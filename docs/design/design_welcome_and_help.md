# ウェルカム表示 ＆ ヘルプ機能 設計書

**作成日:** 2026年10月31日  
**最終更新日:** 2026年11月08日  
**ステータス:** 実装完了  
**対象システム:** `src/gemio/cli/main.py`, `src/gemio/cli/ui.py`  

### 【要約】
CLI起動時に表示するウェルカムバナー（`print_welcome_banner`）と、対話セッション中に `/help`（または `/h`, `help`, `/info`）コマンドで随時呼び出せる詳細操作ガイド・コマンド一覧パネル（`print_help_panel`）の設計仕様を定義します。

---

## 1. 背景と目的

CLI対話セッションを長時間進めると、起動時に表示された操作案内やコマンド一覧がターミナルのログに流れてしまい、再確認できなくなるという課題がありました。
また、起動時は開発作業の開始を告げる華やかですっきりとした「ウェルカム表示」とし、作業中に困った際はいつでも詳細なコマンドリファレンスを呼び出せる「ヘルプ機能」として役割を分離することで、快適なCLIユーザー体験を提供します。

---

## 2. 役割の分担

* **起動時ウェルカム表示**
  * 起動時に1回だけ表示。
  * 視覚的な装飾（アイコンやバナー）で開始を知らせ、現在のプロジェクトパスと使用AIモデルを提示。
  * 必要最小限の基本操作（送信・改行方法）と、詳細を確認するための `/help` コマンドへの案内をすっきりと配置。
* **ヘルプ機能（`/help` コマンド）**
  * 対話セッション中に随時呼び出し可能。
  * モデル切り替え、Web検索、終了などの全コマンドやオプション、ショートカット、安全機能について網羅的に解説。

---

## 3. コマンド仕様

メインループのプロンプト入力において、以下の入力が行われた場合にヘルプパネルを表示し、プロンプト入力待ちに戻ります。

* 対象コマンド（大文字・小文字を区別しない）:
  * `/help`
  * `/h`
  * `help`
  * `/info`

---

## 4. UI・表示設計

Richライブラリの `Panel` を活用し、視認性の高い装飾とカラーテーマで表示します。

### 4.1 起動時：ウェルカムバナー

```text
╭──────────────────────── ✨ Gemio AI Assistant ✨ ────────────────────────╮
│                                                                          │
│   🤖 Welcome to Gemio! あなたの開発作業をサポートします。                 │
│                                                                          │
│   • 対象プロジェクト : /path/to/project                                  │
│   • 使用AIモデル     : gemini-flash-latest                               │
│                                                                          │
│   [基本操作]                                                             │
│     送信   : [Esc] を押した後に [Enter]                                  │
│     改行   : [Enter]                                                     │
│     クリア : [Esc] を押した後に [Backspace]                              │
│                                                                          │
│   💡 コマンド一覧や詳しい使い方は '/help' でいつでも確認できます。       │
│                                                                          │
╰──────────────────────────────────────────────────────────────────────────╯
```

### 4.2 呼び出し時：ヘルプパネル

```text
╭────────────────────── 📖 Gemio 操作ガイド & コマンド一覧 ──────────────────────╮
│                                                                                │
│  【基本操作】                                                                  │
│    • 送信                : [Esc] を押してから [Enter]                          │
│    • 改行                : [Enter] （複数行の入力が可能です）                  │
│    • クリア              : [Esc] を押してから [Backspace] （入力欄を全消去）   │
│                                                                                │
│  【コマンド一覧】                                                              │
│    • /help, /h, help     : この操作ガイドを表示します                          │
│    • /model              : モデル選択メニューを表示（対話形式で切り替え）      │
│    • /model <モデル名>   : 指定したモデルへ即時切り替え                        │
│                            (例: /model argon, /model 3.8, /model 3.5-lite)     │
│    • /search <内容>      : Web検索を実行し、最新情報を「作業前提資料」として取得│
│      (/s <内容>)           ※ 直前の検索結果を踏まえた追加質問・深掘りも可能    │
│        -n, --new         : 検索文脈をリセットして新規検索を開始                │
│        -c, --clear       : 保持している作業前提資料を破棄                      │
│    • /exit, exit, quit   : セッションを終了します                              │
│                                                                                │
│  【安全設計 & 仕様】                                                           │
│    • ファイル書き込み等の変更操作は、事前に確認画面（承認要求）が表示されます。 │
│    • 通常プロンプトでは機密保護のためWeb検索は行われません。                   │
│                                                                                │
╰────────────────────────────────────────────────────────────────────────────────╯
```

## 5. 実装設計

### 5.1 対象ファイル
* `src/gemio/cli/ui.py`
* `src/gemio/cli/main.py`

### 5.2 実装内容
1. **表示関数の実装（`src/gemio/cli/ui.py`）**
   * `print_welcome_banner(...) -> None`:
     起動時にウェルカムバナーを表示する。
   * `print_help_panel(...) -> None`:
     ヘルプおよび操作ガイドを表示する。
2. **コマンド判定（`src/gemio/cli/main.py`）**
   * 入力文字列（前後の空白を除去し小文字化）が `["/help", "/h", "help", "/info"]` のいずれかに一致した場合、`print_help_panel()` を実行して次の入力待ちへ戻る。
