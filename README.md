## 1. Gemioとは（Why Gemio?）

**Gemio** は、Google Gemini API（`google-genai`）を活用した対話型AIアシスタントおよび自律型開発エージェントです。

AIエージェントにファイル操作やプログラムのビルド・テストを任せる際、「**ホストOSの環境を壊されたくない**」「**APIキーや `.env` などの機密情報が漏洩しないか不安**」「**AIが意図しない変更や無限ループで暴走したらどうしよう**」という課題がつきまといます。

Gemioは、「**日常作業は安全性重視の基本モード**」「**コード実行は隔離されたDockerサンドボックス内限定の開発者モード**」という2層アーキテクチャと、多層的なセーフティゲートを組み合わせることで、**安全性と自律的な開発体験の両立**を目指して設計されています。

## 2. 主な特徴（Key Features）

### 🛡️ ① 用途に応じた「2層モード設計」
* **基本モード（デフォルト）**:
  * Docker不要で誰でもすぐに利用可能。指定したプロジェクトフォルダ内でのファイル読み書き・検索・Python構文チェック（AST静的解析）のみを行い、AIが独自にシェルコマンドやスクリプトを生成・実行することはありません。
* **開発者モード（`--dev`）**:
  * 隔離されたDockerコンテナ（またはVS Code Dev Container）内でのみシェルコマンドを実行する `run_sandbox_command` ツールが有効化されます。
  * AIは自らの判断でにコマンドやPythonその他のスクリプト文字列を生成・実行します。
  * Python、TypeScript/Node.js、Go、Rust等の「**コード実装 ➔ テスト・Linter実行 ➔ エラー解析 ➔ 自己修復**」を安全なコンテナ内で自律的に回せます。

### 🔒 ② 最高強度のサンドボックス保護と透明性診断（`/sandbox`）
* **完全オフラインコンテナ（`--network none`）対応**:
  * ホストOS側でGemini APIと通信し、コマンド実行のみを `docker exec` でコンテナへ委譲（Host-Orchestrated モード）できるため、**コンテナの外部ネットワークを完全遮断した状態でも動作**します。
* **危険なコンテナ構成の強制ブロック（`SandboxSecurityError`）**:
  * 特権モード（`--privileged`）、Dockerソケット（`docker.sock`）マウント、ホストネットワーク共有（`--network host`）、およびホストルートマウント等のコンテナ脱獄リスクがある構成を自動検知して起動を拒否します。
* **機密情報のハードブロックと環境変数スクラブ**:
  * `.env`、秘密鍵（`*.pem`, `*.key`, `id_rsa*` 等）、クラウド認証情報、および `.git/` 内部へのAIからのアクセスを常時ブロックし、子プロセス実行時には機密環境変数を自動除去（スクラブ）します。
* **コンテナ環境変数・マウント保護状態の可視化診断（`/sandbox`）**:
  * 起動時および `/sandbox` コマンドで、コンテナ内の各種APIキー・機密環境変数の有無（値は読み取らずキー名のみ検査して強い警告で通知）や、ワークスペース内の各ファイルが「🟢 保護・マスク済」「🔵 作業対象 (`rw`)」「⚪ 読取専用 (`ro`)」「🔴 機密露出警告」のどれに該当するかを一覧テーブルで即座に診断できます。
  * ※本機能は稼働中のコンテナに関する情報の提供が目的であり、コンテナの安全性を保障するものではありません。

### 🚦 ③ 3段階の承認モードと暴走防止機構
* **3段階の承認モード**:
  1. **🟢 通常承認モード（デフォルト）**: すべてのファイル変更・削除・コマンド実行を事前に人間が確認（`y/n/a/k`）。
  2. **🟡 エディットモード（`--edit` / `/edit`）**: ファイル作成・編集は自動承認してテンポよく進め、**削除とシェルコマンド実行のみ都度確認**。
  3. **🔴 トラストモード（`--trust` / `/trust`）**: 信頼できる自作プロジェクト向けに、変更とテスト実行をすべて自動承認して高速に自律実行。
* **サーキットブレーカー＆双方向コミュニケーション（`ask_user`）**:
  * 承認拒否（`n`）の直後にAIが相談なく別の変更を強行しようとした場合、**サーキットブレーカー**が作動して作業ループを強制遮断します。
  * AIが持つ「**指示を完遂しなければならない**」というバイアスによって事故が起こるのを緩和するため、AIからの双方向コミュニケーションツール（`ask_user`）を備えています。
  * 仕様の曖昧さや複数の実装方針、コンテナ環境の不備がある場合に、AIが人間に判断を仰ぐ必要があると判断すると `ask_user` ツールで選択肢を提示して人間に判断を仰ぎます。指示を直接入力することも可能です。

### 🌐 ④ 機密を漏らさない人間介在型Web検索支援（`+WEB` / `/web`）とエラー自動回復
* **人間介在型 Web 検索支援（Human-Assisted Web Search）**:
  * 作業中のAIが外部情報や公式ドキュメントの確認を必要と判断した場合、ローカル非公開情報を除外した**推奨検索クエリ・確認観点**を専用ダイアログで提示します。ユーザーは自身のブラウザで検索して必要な箇所を貼り付け（リアルタイムの**入力テキスト診断**で機密情報誤ペーストをブロック・不可視文字を無害化）、**「通常応答」または「作業前提資料（`/materials`）」**として提供できます（ヘッダーの **`+WEB` / `-WEB` バッジ**や `/web off` でいつでも無効化可能）。
* **サーバーエラー自動回復とトークン管理**:
  * Gemini APIの混雑（503）やレート制限（429）発生時は指数バックオフで自動リトライし、万一中断してもツール実行結果と対話ロールの整合性を維持します。
  * `/tokens` によるコンテキスト量・累積トークン消費量の可視化と、`/clear` による即時セッションリセットに対応しています。

## 3. クイックスタート（Quick Start）

### 3.1 動作要件
* **Python**: 3.11 以上（3.11 / 3.12 / 3.13）
* **対応OS**: Windows 10 (22H2以降) / 11、macOS、Linux、WSL2
* **ターミナル**: モダンな ANSI / 仮想ターミナル対応エミュレータ（推奨画面サイズ: `80列 × 24行` 以上）
  * Windows: Windows Terminal（推奨）、VS Code / Cursor 統合ターミナル等（※旧 `conhost.exe` 単体は非サポート）
  * macOS / Linux: Terminal.app、iTerm2、Ghostty、WezTerm、VS Code Remote / Dev Containers、対話型 SSH (`docker exec -it` 含む)
* **APIキー**: Google AI Studio 等で取得した Gemini API キー（OSのシステム環境変数 `GEMINI_API_KEY` に設定）
* **Docker**: Docker Desktop または Docker Engine（※ `--dev` 開発者モードを使用する場合のみ）

### 3.2 インストール
Gemioはプロトタイプ版のため、仮想環境にインストールすることを推奨します。

```bash
# 1. リポジトリのクローン
git clone https://github.com/koyama-hiro-15/gemio.git
cd gemio

# 2. 仮想環境の作成と有効化
python -m venv .venv
# macOS / Linux / WSL2:
source .venv/bin/activate
# Windows (PowerShell): .venv\Scripts\Activate.ps1

# 3. 依存パッケージと gemio のインストール
pip install --upgrade pip
pip install -r requirements.txt
pip install -e .
```

### 3.3 APIキーの設定（システム環境変数）
Gemioはワークスペース内への平文 `.env` 配置による漏洩事故を防ぐため、**ホストOSのシステム環境変数 `GEMINI_API_KEY`** からAPIキーを読み込みます。

**Windows (PowerShell):**
```powershell
$env:GEMINI_API_KEY="あなたのAPIキー"
```

**macOS / Linux / WSL2 (bash / zsh):**
```bash
export GEMINI_API_KEY="あなたのAPIキー"
```

### 3.4 起動方法

#### パターン1：基本モードで起動する（Docker不要・一般作業向け）
事前に仮想環境を有効化した上で、以下のコマンドで起動します。
```bash
# カレントディレクトリを作業対象として起動
python -m gemio
# （または `gemio` コマンド）

# 対象のプロジェクトフォルダを指定して起動
python -m gemio /path/to/your_project
```

#### パターン2：開発者モードで起動する（Dockerサンドボックス連携）
本リポジトリには、セーフティゲートと4分類保護基準（設定ファイルの `:ro` 保護、`.venv` 隔離、`--network none` 等）を満たす `Dockerfile` と `compose.yaml` が同梱されています。

```bash
# 1. サンドボックス用Dockerコンテナをバックグラウンド起動
docker compose up -d

# 2. 開発者モードで接続して起動（コンテナは自動検出されます）
python -m gemio . --dev

# ファイル編集のみ自動承認にする場合（エディットモード）
python -m gemio . --dev --edit

# 作業終了時のコンテナ停止
docker compose down
```

## 4. 基本操作とスラッシュコマンド（Textual TUI）

### キーボード操作（複数行入力・独立ログスクロール対応）
| 操作 | キー操作 | 説明 |
| :--- | :--- | :--- |
| **プロンプト送信** | **`Ctrl+J`** | 入力欄のプロンプトまたはスラッシュコマンドを送信します |
| **改行** | `Enter` | 入力欄内で新しい行へ改行します |
| **入力欄全クリア** | **`F7` ➔ `Backspace`** | 全テキストを選択して消去します（`Ctrl+Z` / `Ctrl+Y` で Undo / Redo 可能） |
| **ログスクロール** | `PageUp` / `PageDown` | 入力欄にフォーカスしたまま過去の対話タイムラインをスクロールします |
| **ターン中断** | **`Esc`** *(AI実行中)* | **アプリを終了せず**、実行中のターンと子プロセスのみを停止して入力待ちへ戻ります |
| **コマンドパレット** | **`Ctrl+P`** | 全コマンド・モデル切替・設定変更を検索して実行します |
| **クイック機能** | `F1`: ヘルプ / `F2`: モデル / `F3`: 承認切替 / `F4`: 入力欄 | ワンキーで主要モーダル表示・承認切替・入力欄フォーカス移動を実行します |
| **テキストコピー** | 各カードの `[Copy]` ボタン / `/cp` | 入力やAI回答をクリップボードへコピーします（OSC 52対応） |
| **終了** | **`Ctrl+Q`** | Gemio TUI を安全に終了します |

### 主なスラッシュコマンド
| コマンド | 説明 |
| :--- | :--- |
| `/help` (`/h`) | キー操作・コマンド一覧・安全仕様のタブ切り替え式ヘルプモーダルを表示 |
| `/model [名前]` | 使用するGeminiモデルを選択モーダルまたは直接指定で切り替え（例: `/model`, `/model lite`） |
| `/web [on\|off]` | AIからの外部検索協力依頼ツール（`+WEB` / `-WEB`）の有効・無効を切り替え |
| `/materials` (`/mat`) | 作業前提資料の一覧閲覧・手動追加・削除・クリアを行う管理モーダルを表示 |
| `/edit [on\|off]` | **エディットモード**（作成・編集は自動承認、削除・コマンドは都度確認）の切り替え |
| `/trust [on\|off]` | **トラストモード**（事前同意の上で変更・コマンド実行を自動承認）の切り替え |
| `/sandbox` (`/status`) | Dockerサンドボックス設定とファイル保護状態（`ro`/`rw`/マスク）を一覧表モーダルで診断 |
| `/tokens` (`/usage`) | 現在のコンテキスト健全性と累積トークン消費量の内訳表モーダルを表示 |
| `/copy` (`/cp`) | 直近のAI回答テキストをクリップボードへコピー |
| `/compact [残す数]` | 古い対話ターン群を構造化要約へ圧縮してコンテキストをスリム化 |
| `/rewind [ターン数]` (`/undo`) | 直近の対話ターンを指定数だけ巻き戻してタイムラインから除去 |
| `/clear` (`/reset`) | 会話履歴とトークン統計をリセットして新規セッションを開始（全消去: `/clear --all`） |
| `/exit` (`exit`, `quit`) | Gemioを終了 |
